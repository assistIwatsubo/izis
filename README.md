# IZIS - FIX the UI -

**悪いUIをクリックorタップで撃退し、良いUIに変えよう！**

<img width="1920" height="869" alt="IZIS1" src="https://github.com/user-attachments/assets/a4467cdb-f145-4dfe-a69c-469655b972e0" />

IZISはUI修正ゲーム風SPAです。
方言の「いずい（靴の中に小石が入るなど、ちょっと不快な状態を表現する言葉）」と「is」を掛け合わせ、「いずいのは...」という意味で「IZIS」と付けました。

実在するプロダクトを非難する意思は一切ありませんので、ゲームのモチーフには童話を採用しています。
